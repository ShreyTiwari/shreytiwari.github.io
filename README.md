# Personal Academic Website

Source for [shreytiwari.com](https://www.shreytiwari.com), served by GitHub Pages from `master`.  
Built with plain HTML, CSS and vanilla JavaScript—no build tools or frameworks required.

## 🔧 Quick Start
1. **Clone** this repository  
   ```bash
   git clone https://github.com/ShreyTiwari/shreytiwari.github.io.git
   cd shreytiwari.github.io
   ```
2. **Serve** it locally and open http://localhost:8000  
   ```bash
   python3 -m http.server
   ```
   (Opening `index.html` directly works for the homepage, but the blog's directory links need a server.)

## 📦 External Dependencies
CDN-hosted, no local installs needed:
1. Font Awesome 6 – icons
2. Academicons – the Google Scholar icon
